# Windows x64 Server Binary

This directory is reserved for the Windows x64 build of the Ork demo server.

## Current Status

**Not yet available.** The Ork SDK does not yet support Windows TLS backend.

## Prerequisites for Windows Support

- MSVC 2022+ or MinGW-w64
- vcpkg with OpenSSL and libsodium
- Windows TLS backend implementation (in progress)
